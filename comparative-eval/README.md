# Comparative Decision Evidence

This subtree is reserved for public evidence from bounded semantic-decision studies. It is separate from the BM3–BM6 lifecycle benchmark series.

The first planned study is routing-semantic-v1. Its implementation is preregistered before the independent oracle and full results exist.

The merged study stack is Agent-Workflow 0.11.10, agent-workflow-benchmark 0.4.0, and agent-workflow-comparative-eval 0.2.0. Agent-Workflow remains authoritative; TypeSafe/Jev supplies typed semantic evidence only.

No effectiveness result should be inferred from this scaffold.
