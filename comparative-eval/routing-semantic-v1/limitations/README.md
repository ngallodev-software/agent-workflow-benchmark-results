# Current Limitations

This directory now reflects a frozen inference design and corpus, but it is not a completed study.

Current BM3–BM5 TypeSafe qualification calls are historical integration evidence and must not be pooled into this study. They lack the independent frozen oracle and sample design required here.

No current artifact in this subtree establishes that Jev/TypeSafe improves correctness, latency, token use, cost, or downstream software quality.


The remaining empirical dependency is the independently adjudicated frozen oracle. Live comparative inference must not begin until that oracle is frozen and hashed.
